# バグ修正要件書 - コード進行と歌詞の表示問題

## Introduction

コード進行と歌詞の表示に複数の問題が発生しています。マイナーコード、7thコード、sus4コード、分数コードが全く表示されず、すべてメジャーコードとして表示されています。また、歌詞が「ん」のみしか表示されない問題も発生しています。これらの問題により、ユーザーは正確なコード進行と歌詞を確認できず、アプリケーションの主要機能が使用できない状態です。

## Bug Analysis

### Current Behavior (Defect)

1.1 WHEN コード推定モジュールがコードを認識する THEN システムはすべてのコードをメジャーコード（ChordQuality.MAJOR）として分類する

1.2 WHEN マイナーコード（Em7、F#m7など）が音声に含まれる THEN システムはそれらをメジャーコードとして表示する

1.3 WHEN 7thノートのコード（A7、B7、Dmaj7など）が音声に含まれる THEN システムは7thの情報を検出・表示しない

1.4 WHEN sus4コード（A7sus4、B7sus4など）が音声に含まれる THEN システムはsus4の情報を検出・表示しない

1.5 WHEN 分数コード（A/G、A/Dなど）が音声に含まれる THEN システムはベース音を検出・表示しない

1.6 WHEN コード進行を表示する THEN システムは1行あたりの小節数が仕様（16小節）と異なる配置で表示する

1.7 WHEN 歌詞文字起こしモジュールが日本語歌詞を処理する THEN システムは「ん」のみを表示し、他の文字が表示されない

### Expected Behavior (Correct)

2.1 WHEN コード推定モジュールがコードを認識する THEN システムはコードの質（メジャー、マイナー、ディミニッシュ、オーグメント）を正確に判定する

2.2 WHEN マイナーコードが音声に含まれる THEN システムはマイナーコードテンプレートを使用してマイナーコードとして検出し、「Em7」「F#m7」などと表示する

2.3 WHEN 7thノートのコードが音声に含まれる THEN システムは7thの音（短7度または長7度）を検出し、「A7」「Dmaj7」などと表示する

2.4 WHEN sus4コードが音声に含まれる THEN システムは3度の代わりに4度の音を検出し、「A7sus4」「B7sus4」などと表示する

2.5 WHEN 分数コードが音声に含まれる THEN システムはベース音検出機能を使用してベース音を特定し、「A/G」「A/D」などと表示する

2.6 WHEN コード進行を表示する THEN システムは1行に16小節を配置し、コードを4小節に1つ、2小節に1つ、または必要に応じて1小節に1つの間隔で表示する

2.7 WHEN 歌詞文字起こしモジュールが日本語歌詞を処理する THEN システムはWhisperモデルの出力をUTF-8エンコーディングで正しく処理し、すべての日本語文字を表示する

### Unchanged Behavior (Regression Prevention)

3.1 WHEN メジャーコードが音声に含まれる THEN システムは引き続きメジャーコードを正確に検出・表示する

3.2 WHEN コード推定の信頼度が計算される THEN システムは引き続き信頼度スコアを正確に計算し、低信頼度コード（<70%）を視覚的に区別する

3.3 WHEN ユーザーがコードをクリックする THEN システムは引き続きコードの詳細情報（時間、信頼度）を表示する

3.4 WHEN 現在再生位置がコードセグメント内にある THEN システムは引き続きそのコードを「現在再生中」として強調表示する

3.5 WHEN 歌詞セグメントに関連するコードが存在する THEN システムは引き続き歌詞とコードの時間的な対応関係を正しく表示する

3.6 WHEN 音声にボーカルが含まれる THEN システムは引き続きボーカル分離機能を使用してコード推定の精度を向上させる

3.7 WHEN クロマ特徴が抽出される THEN システムは引き続き無音区間を適切に処理し、ゼロベクトルとして扱う

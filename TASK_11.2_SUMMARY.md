# Task 11.2 Summary: Markdown Report Generator

## Overview
Successfully implemented the `_generate_markdown_report` method in the BenchmarkTool class to generate formatted markdown evaluation reports.

## Implementation Details

### Core Functionality
The markdown report generator creates a comprehensive, human-readable report with:

1. **Title Section**: Clear report header
2. **Summary Section**: Total songs processed count
3. **Aggregate Statistics Table**: 
   - Mean, Standard Deviation, Min, and Max for each metric
   - Formatted as a markdown table
   - Percentages for accuracy metrics (2 decimal places)
   - Float values for DTW distance (4 decimal places)

4. **Detailed Results by Song**:
   - Individual song sections with numbered headers
   - Metrics table for each song
   - Predicted and ground truth chord sequences
   - Processing time for each song

### Key Features

#### Formatting
- **Percentages**: Accuracy metrics displayed as percentages (e.g., "87.65%")
- **DTW Distance**: Displayed with 4 decimal places (e.g., "0.1234")
- **Processing Time**: Displayed with 2 decimal places and "s" suffix (e.g., "2.30s")
- **Chord Sequences**: Displayed in code blocks with pipe separators (e.g., `` `D | A | Bm7 | G` ``)

#### Error Handling
- Handles empty results list gracefully
- Raises IOError if unable to write to output path
- Logs success/failure messages

#### Edge Cases
- Empty results: Shows "No results to display" message
- Single song: Calculates statistics with 0 standard deviation
- Multiple songs: Full aggregate statistics with proper calculations

## Usage Example

```python
from pathlib import Path
from src.evaluation.benchmark import BenchmarkTool

# Create benchmark tool
tool = BenchmarkTool()

# Run benchmark
results = tool.run_benchmark(
    audio_dir=Path("test_data/audio"),
    ground_truth_dir=Path("test_data/ground_truth")
)

# Generate markdown report
tool.generate_report(
    results=results,
    output_path=Path("evaluation_report.md"),
    format='markdown'
)
```
